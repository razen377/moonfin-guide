# 🌙 Installer Moonfin sur Samsung et LG

Moonfin n’est pas disponible dans les magasins d’applications officiels des télévisions **Samsung** et **LG**.  
Il faut donc l’installer manuellement (sideload). C’est simple et rapide.

---

## 📺 Samsung (Tizen)

### Méthode recommandée : Apps2Samsung

1. **Active le mode développeur** sur ta TV :
   - Va dans **Apps**
   - Sur la télécommande, tape rapidement : **1 2 3 4 5**
   - Active le mode développeur et entre l’adresse IP de ton ordinateur

2. **Télécharge Apps2Samsung** sur ton PC (Windows) :  
   👉 [https://github.com/Apps2Samsung/Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung)

3. Lance l’outil, sélectionne ta télévision et installe **Moonfin** depuis le catalogue.

> Alternative : tu peux aussi télécharger le fichier `.wgt` et l’installer manuellement.

### 📥 Téléchargement direct Samsung
- Dernière version : [https://github.com/Moonfin-Client/Smart-TV/releases/latest](https://github.com/Moonfin-Client/Smart-TV/releases/latest)  
  (prends le fichier `Moonfin_Tizen_Regular_*.wgt`)

---

## 📺 LG (webOS)

### Méthode standard

1. **Crée un compte développeur LG** (gratuit) :  
   👉 [https://webostv.developer.lge.com](https://webostv.developer.lge.com)

2. **Sur la télévision** :
   - Installe l’application **Developer Mode** depuis le LG Content Store
   - Ouvre-la, connecte-toi et active le **Dev Mode**
   - Note l’adresse IP et le **passphrase** affichés

3. **Sur ton ordinateur** :
   - Installe **webOS Dev Manager**
   - Télécharge le fichier `.ipk` de Moonfin
   - Ajoute ta TV dans Dev Manager et installe le fichier

### 📥 Téléchargement direct LG
- Dernière version : [https://github.com/Moonfin-Client/Smart-TV/releases/latest](https://github.com/Moonfin-Client/Smart-TV/releases/latest)  
  (prends le fichier `Moonfin_webOS_*.ipk`)

### 💡 Astuce LG
Si ta télévision a déjà le **Homebrew Channel**, Moonfin y est disponible directement. Tu n’as rien d’autre à faire.
